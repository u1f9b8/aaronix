# Aaronix Architecture

This folder contains architecture records, diagrams, and supporting resources.

- [Architecture Decision Records](adrs/index_adrs.md)
- [Diagrams](diagrams/index_diagrams.md)
- [Resources](resources/index_arch_resources.md)
- [Project vision](../vision.md)

The current ADR set was seeded from reusable Argaile decision-record discipline and rewritten for Aaronix's OS goals: MINIX fidelity, Rust-first implementation, Phase 1 bootstrapping, testable milestones, and later Linux/Windows/GUI phases.

Architecture documents should stay connected to epics and PM files. A design decision belongs in an ADR; a capability narrative belongs in an epic; execution state belongs in PM.
