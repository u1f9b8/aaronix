# Aaronix Project Management

PM files coordinate execution. They track milestones, tasks, subtasks, acceptance evidence, and implementation status. PM files should be updated after implementation work so the plan reflects reality.

## PM File Expectations

Each PM file should include:

- linked epic,
- linked ADRs,
- milestones,
- tasks and subtasks,
- acceptance checks,
- human-visible demonstration,
- status,
- and implementation notes after completion.
